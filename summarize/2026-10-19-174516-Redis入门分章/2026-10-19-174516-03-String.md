**第03章｜String：保存一份商品详情**

**本章解决什么问题**

应用从数据库查到一件商品后，怎样把整份详情存进 Redis，并在下次访问时取出来？String 是最容易上手的选择。

**通俗解释**

String 可以理解为一个有名字的存储格。Key 是格子的名字，Value 是里面保存的内容。Value 可以是普通文本，也可以是序列化后的 JSON。商品资料包含多个字段，但只要把整段 JSON 交给 `SET`，它在 Redis 中就是一个 String。

**一个商品例子**

下面先删除本章的练习 Key，确保示例从空白状态开始。价格使用“分”作为单位。以下命令在已连接 Redis 的 `redis-cli` 中执行。

```text
DEL learn:redis:product:1001
SET learn:redis:product:1001 '{"id":1001,"name":"keyboard","price_cents":29900}'
GET learn:redis:product:1001
EXISTS learn:redis:product:1001
```

**预期现象**

`SET` 返回 `OK`。`GET` 取回整段 JSON；客户端可能显示用于转义的反斜杠。`EXISTS` 返回整数 `1`，表示这个 Key 已存在。

**一点注意**

普通 `GET` 不会把 JSON 自动拆成字段，应用需要自行解析。再次对同一个 Key 执行 `SET`，会覆盖原来的整份内容。练习结束后，可以用上面的 `DEL` 删除练习数据。

参考：[String 官方文档](https://redis.io/docs/latest/develop/data-types/strings/)
