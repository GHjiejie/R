# Kafka 入门｜从订单事件到可靠消息系统

用户支付了一笔订单，订单服务需要更新业务状态，积分服务需要增加积分，通知服务需要发送消息，分析服务还想统计成交额。让这些服务围绕同一个事件协作，是理解 Kafka 的一个具体起点。

本系列用一条 `order.paid` 事件贯穿 17 章：先建立消息流转的基本认识，再理解消费进度与可靠性，最后回到重试、积压、数据库一致性和技术选型。每章只处理一个主要问题，包含机制、示例、预期现象、使用边界和练习，读完后可以独立回顾。

## 本系列的版本与实验约定

教学基线为 **Apache Kafka 4.1.2、KRaft 模式**，与本仓库现有架构实验台使用的镜像保持一致；这是一条固定的学习基线，不表示它是最新版本。不同版本的默认配置和消费组协议存在变化，文章在相关位置说明适用范围。除非特别说明，“消费组”指使用 `subscribe` 的普通 Consumer Group，不把 Share Group 的分配与确认规则混入基础解释。

示例围绕 `event_id`、`order_id` 和 `order.paid`，使用 `learn-kafka-` 前缀隔离学习主题。代码中的事件和订单均为虚构测试数据。配置项若按 Java 客户端书写，会标明配置语境；其他语言的客户端需核对各自 API。

命令结果均为**给定初始条件下的预期现象**，没有把教学推演当成真实压测或故障测试。阅读文章无需启动任何服务；需要跟随 CLI 操作时，按下面的单节点环境准备。

## 准备一个独立的本地环境

前置条件：Docker Engine 或 Docker Desktop 正常运行，本机 `9092` 端口空闲，能够下载官方镜像。先确认没有名为 `kafka-learn` 的已有容器；若名称已被使用，选择新的实验名称并同步修改后续命令。

```bash
docker run -d --name kafka-learn \
  -p 127.0.0.1:9092:9092 \
  apache/kafka:4.1.2
```

启动需要一点时间，可以先查看日志，再执行创建命令。命令行工具在容器内运行，不需要在宿主机另外安装 Java 和 Kafka。

```bash
docker logs kafka-learn

docker exec kafka-learn /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create --if-not-exists --topic learn-kafka-orders \
  --partitions 3 --replication-factor 1

docker exec kafka-learn /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --describe --topic learn-kafka-orders
```

预期描述中能看到 3 个分区，每个分区有 1 个副本。Leader 的编号以实际输出为准。`--if-not-exists` 只避免重复创建报错，不会把已有主题的配置改成示例值；若之前建过不同分区数的同名主题，应先读取实际配置，再决定使用新主题重新实验。

下面是一条可用于各章讨论的事件。这个 JSON 只定义事件内容，不会因为写在文章里就自动发布。

```json
{
  "event_id": "evt-learn-1001-paid",
  "event_type": "order.paid",
  "schema_version": 1,
  "order_id": "order-1001",
  "amount_cents": 29900
}
```

单节点环境适合观察 Topic、分区、Key、消费组和位移，**无法验证跨 Broker 副本容灾**。第 09、10 章讨论多节点配置时会明确额外条件。想进一步观察真实的 3 Controller + 3 Broker 拓扑，可以按仓库 仓库内的 `demo-kafka-architecture/README.md` 准备另一套实验，避免将两套地址和主题混用。

## 停止与清理

停止本次容器会暂时关闭实验 Kafka；再次启动可以继续使用同一容器内的数据。

```bash
docker stop kafka-learn
docker start kafka-learn
```

如果确认本次独立实验已结束，先停止容器，再删除这个实验容器。上述启动方式没有挂载持久卷，删除容器会删除它内部保存的学习消息。命令只针对自己创建的 `kafka-learn`。

```bash
docker stop kafka-learn
docker rm kafka-learn
```
